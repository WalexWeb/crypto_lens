# 📈 Crypto Lens

Современная панель криптовалют, построенная на Next.js, с отслеживанием цен в реальном времени, интерактивными свечными графиками и анализом трендовых валют.


## ✨ Возможности

- **📊 Отслеживание цен в реальном времени**: Живая цена и рыночные данные по каждой монете, обновление через WebSocket.
- **📈 Интерактивные свечные графики**: Профессиональные графики (OHLC) с лайв-обновлением, переключение таймфрейма.
- **🔥 Трендовые валюты**: Список популярных криптовалют с динамикой за 24ч.
- **📋 Таблицы последних сделок**: Живой поток сделок (buy/sell) с ценой, объемом, временем.
- **🔍 Детальная страница монеты**: Актуальная информация, ссылки на сайт, блокчейн-эксплорер, комьюнити.
- **💡 Категории и обзоры**: Группировка монет по категориям, краткий обзор рынка.
- **⏱ Пагинация**: Быстрая навигация по списку монет с кастомной пагинацией.
- **🎨 Современный интерфейс**: Красивая тёмная тема, адаптивный дизайн, UI-компоненты shadcn/ui.
- **⚡ Быстрый и легковесный**: Построен на Next.js 16, оптимизирован для высокой производительности.

## ⚙️ Архитектура и технологии

- **Next.js 16 (App Router)** — серверные и клиентские компоненты
- **TypeScript** — строгая типизация
- **Tailwind CSS** — стилизация и адаптивность
- **shadcn/ui** — UI-компоненты
- **WebSocket** — получение лайв-данных (цена, сделки, OHLCV)
- **CoinGecko API** — основной источник данных
- **Lightweight Charts** — графики

## 🌐 Интеграция с API

Приложение интегрируется с CoinGecko API для получения:

- **Детальной информации о валютах**: Текущая цена, рыночная капитализация, объем и исторические данные
- **OHLC данные**: Цены открытия, максимума, минимума, закрытия для визуализации графиков
- **Трендовые валюты**: Популярные криптовалюты на основе поисковых трендов
- **Рыночные категории**: Категории криптовалют и их производительность

## 🧩 Структура проекта

- `app/` — страницы приложения (главная, монеты, детали монеты)
- `components/` — UI и бизнес-компоненты (LiveDataWrapper, CoinHeader, CandleStickChart, DataTable и др.)
- `hooks/` — кастомные хуки (например, useWebsocket для лайв-данных)
- `lib/` — утилиты и функции работы с API
- `public/` — статические файлы

## 🛠 Установка

1. **Клонируйте репозиторий**
   ```bash
   git clone https://github.com/your-username/crypto-lens.git
   cd crypto-lens
   ```

2. **Установите зависимости**
   ```bash
   npm install
   # или
   yarn install
   # или
   pnpm install
   # или
   bun install
   ```

3. **Запустите сервер разработки**
   ```bash
   npm run dev
   # или
   yarn dev
   # или
   pnpm dev
   # или
   bun dev
   ```

4. **Откройте браузер**
   Перейдите по адресу [http://localhost:3000](http://localhost:3000)
