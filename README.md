# 📈 Crypto Lens

Современная панель криптовалют, построенная на Next.js, с отслеживанием цен в реальном времени, интерактивными свечными графиками и анализом трендовых валют.

## ✨ Возможности

- **📊 Отслеживание цен в реальном времени**: Живая цена  с детальными рыночными данными
- **📈 Интерактивные свечные графики**: Профессиональные графики на базе Lightweight Charts
- **🔥 Трендовые валюты**: Лучшие трендовые криптовалюты с изменениями цены за 24 часа
- **🎨 Современный интерфейс**: Красивая темная тема с адаптивным дизайном
- **⚡ Быстрый и легковесный**: Построен на Next.js 16 с оптимизированной производительностью

## 🚀 Технологический стек

- **Фреймворк**: Next.js 16 с React 19
- **Язык**: TypeScript
- **Стилизация**: Tailwind CSS
- **UI Компоненты**: shadcn/ui
- **Графики**: Lightweight Charts
- **Источник данных**: CoinGecko API

## 🛠 Установка

1. **Клонируйте репозиторий**
   ```bash
   git clone https://github.com/your-username/crypto-lens.git
   cd crypto-lens
   ```

2. **Установите зависимости**
   ```bash
   npm install
   # или
   yarn install
   # или
   pnpm install
   # или
   bun install
   ```

3. **Запустите сервер разработки**
   ```bash
   npm run dev
   # или
   yarn dev
   # или
   pnpm dev
   # или
   bun dev
   ```

4. **Откройте браузер**
   Перейдите по адресу [http://localhost:3000](http://localhost:3000)


## 🌐 Интеграция с API

Приложение интегрируется с CoinGecko API для получения:

- **Детальной информации о валютах**: Текущая цена, рыночная капитализация, объем и исторические данные
- **OHLC данные**: Цены открытия, максимума, минимума, закрытия для визуализации графиков
- **Трендовые валюты**: Популярные криптовалюты на основе поисковых трендов
- **Рыночные категории**: Категории криптовалют и их производительность
